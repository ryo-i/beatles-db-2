## YouTube Music

曲の詳細に、その曲を聴ける YouTube Music へのリンクを置きます。370曲のそれぞれに Wikipedia のリンクがあるわけではありません。`source` に URL があるのは「My Bonnie」の1曲で、英語版 Wikipedia が2件です。About のディスコグラフィ案内と、備考で出典に触れている29曲は、曲ごとのリンクではありません。

`music.youtube.com` は iframe で開けません。専用の埋め込みプレイヤーもありません。`watch?v=` の動画 ID がある曲だけ、詳細ページで通常の YouTube プレイヤーを出します。

```html
<iframe src="https://www.youtube.com/embed/動画ID"></iframe>
```

公式の音源や MV で、その ID が公開されているものに限られます。自分のライブラリの曲や、地域制限のある音源は再生できません。370曲すべてにはプレイヤーを置きません。

ジャケット画像は、こちらで保存して並べません。権利はレーベルや写真家にあり、YouTube Music 上の画像は再生用です。公式ジャケットそのものとは限らず、URL も変わります。プレイヤーの中に YouTube が表示する画像は、プレイヤーの一部です。今のアートワーク列は、写真家などのクレジット文字列だけで、画像 URL はありません。

## 曲の解説

長い解説は `data/data.json` に書きません。あそこはスプレッドシートの書き出しのままにします。セルの中で ` / ` を足すと読みにくくなり、スプシを書き出すと手で書いた文章が上書きされます。

書く場所は、曲の id ごとの Markdown です。ファイル名は曲名ではなく id にします。「My Bonnie」はシングルの id 1 と、コンピレーションの id 47 で別の曲行です。

```text
content/tracks/1.md
content/tracks/47.md
```

```markdown
---
id: 1
title: My Bonnie
catalog: TB-S-01
---

ハンブルクで録音。トニー・シェリダンのバックバンドをビートルズが務めた。

トラディショナルソングでいかにもなゆったりした始まり方から、切れ味抜群のギターが入り、タイトなエイトビートの曲になる。
```

短い事実の備考は、これまでどおりスプシの `remarks` に残します。この文章はサイト側の解説で、誰でも投稿するコメントとは別です。投稿画面を足すときは管理者だけが書けます。画面も取り込みも、まだこのファイルを読みません。曲の詳細を作るときに、id が一致するファイルだけ備考の下へ出します。

## 同じ曲名の別リリース

曲名が2つ以上のリリースに入っているのは27曲で、いちばん多くて3リリースです。Love Me Do は `BE-S-01` と `BE-A-01`、My Bonnie は `TB-S-01` と `TB-CA-01` です。詳細から、同じ `title` の他の曲行へリンクします。テーブルは増やしません。

## リリースの曲順

今の一覧は370曲を1行ずつ並べます。59リリースのそれぞれを、シングルなら A/B、アルバムなら disc と side の順の曲目として見せます。`disc`、`side`、`number` がすでにあります。

## カバー

`track_originals` の407行のうち、`The Beatles` は208行です。George Harrison、John Lennon、Paul McCartney、Ringo Starr、Yoko Ono、Plastic Ono Band も、自分たちの曲として残します。それ以外の名前が付いた曲をカバーとして一覧します。Carl Perkins が4行、Larry Williams が4行、`traditional` が5行です。

## 映画と MV

映画か MV の監督が付いている曲だけを一覧します。370曲のうち、映画が78曲、MV が26曲、両方あるのが4曲で、どちらかがあるのは100曲です。映画のついたリリースは12、MV は21です。Can't Buy Me Love の映画は Richard Lester、I Feel Fine の MV は Joseph McGrath です。

`film` は `film director`、`mv` は `mv director` として、すでに曲のクレジットに入っています。リリースの形式にはしません。映画だけ、MV だけ、どちらか、の3つに絞れます。

## 一覧の並び

初期の並びはスプレッドシートの順で、発売日の古い方からです。日付だけで並べ替えても、並びはほとんど変わりません。同じ発売日の中は `disc`、`side`、`number` のままにします。

曲名順は A から Z です。曲名はすべて英字です。2リリース以上にある27の曲名は、この順だと隣に並びます。

カタログ番号順は、日付をまたいで `BE-A-01` や `BE-S-01` のように番号ごとに集まります。
